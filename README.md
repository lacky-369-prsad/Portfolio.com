# Lacky's Builder Page

## What it is
My personal portfolio website. It tells people who I am, what skills I have, what projects I have built and how to contact me.

## Why I made it
I made this page to show my skills and projects in one place, and to practice HTML and CSS by building a complete website.

## Sections
- About: a short introduction about me
- Skills: HTML, CSS, JavaScript and React
- Projects: some of my projects
- Contact: links to my GitHub and email
